-- Zepto E-commerce Inventory Data Analysis using SQL

This project focuses on analyzing Zepto's e-commerce inventory dataset using SQL and PostgreSQL to explore product pricing, discounts, stock availability, and product categories.

-- Key Activities
1. Explored the dataset to understand its structure and identify missing values and duplicates.
2. Cleaned data by handling zero-price records and converting prices from paise to rupees.
3. Analyzed product pricing, discounts, inventory availability, and category-wise trends.
4. Wrote SQL queries to answer business questions and derive meaningful insights from inventory data.

--- Tools & Technologies
1. PostgreSQL
2. SQL
3. pgAdmin

--- Objective
To strengthen SQL and data analytics skills through practical e-commerce data analysis and develop insights that support business decision-making.
